# Bookhand product context

## Product name

Bookhand

## Purpose

A calm local-first ebook reader that WebMCP can turn into an adaptive study
environment. The dramatic demo is not “chat with a book.” It is an agent using
the book's precise semantic controls to construct useful explanations, worked
examples, visualizations, interactive labs, notes, and reading-format changes
inside the page.

## Experience principles

- Reading remains the primary surface; AI additions should support rather than
  bury the text.
- The user can move naturally between book context, focused explanation, and a
  zoomed-out study board.
- Persistent changes are legible and reversible.
- Native blocks should feel polished. Generated labs may be more expressive but
  remain visibly bounded and disposable.
- Mobile is a first-class reading surface; the initial reference phone is a
  Pixel 7.

## Visual direction

Bookish and tactile rather than dashboard-like. Strong typography, generous
reading measure, restrained chrome, and clear spatial changes between reading,
annotation, and study modes. Avoid card grids, nested panels, generic AI
gradients, and walls of equally weighted controls.
