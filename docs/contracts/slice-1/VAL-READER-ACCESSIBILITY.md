# VAL-READER-ACCESSIBILITY: Operable and understandable reader chrome

Surface: browser.
Needs: VAL-READER-RESPONSIVE and the persistent Slice 2 study board/panel surface.
Behavior: Controls expose accurate names, roles, states, and logical keyboard order with visible focus. Contents, Text, and Study close via their visible control and Escape, then restore focus to the invoker. Navigation and Study this are keyboard operable; coarse-pointer targets measure at least 44 by 44 CSS pixels; reduced motion preserves equivalent state understanding. Normal text meets 4.5:1 contrast and large text plus meaningful non-text controls/states meet 3:1 across library, reader, panels, sheets, warnings, errors, focus, and disabled states.
Evidence: Accessibility scan, manual keyboard trace, focus before/after observations, target measurements at Pixel viewport, reduced-motion state comparison, and computed foreground/background contrast measurements for every named state and surface.
