# VAL-MOBILE-CHROME: Reading-first mobile geometry

Surface: Chromium touch emulation at 412 by 915, 320 pixels, landscape, safe-area emulation, and 200 percent zoom.
Needs: `VAL-READER-RESPONSIVE`, `VAL-READER-SHELL`, and production preview.
Behavior: Permanent side rails do not reduce book width and the book host is at least 92 percent of the visual viewport width at 412 pixels and 90 percent at 320 pixels; primary navigation remains reachable. Secondary chrome hides after a completed page change or 2.5 seconds without pointer, touch, keyboard, or focus activity, and returns on a center-surface tap, keyboard focus/navigation, panel close, or pointer movement from a mouse-capable device. Chrome never hides while it or a panel contains focus. A navigation control that changes page retains visible focus and resets the idle timer; touch-zone navigation moves focus to the book host before chrome may recede. No content is obscured by browser/safe-area UI; app-shell horizontal overflow is absent; long metadata remains intentional.
Evidence: Annotated screenshots and geometry at every setup; exact book-to-viewport ratios; timed show/hide and every return-condition trace; focused-control non-hide and navigation focus-relocation trace; CDP safe-area and overflow measurements; automated half-width reflow proxy plus separately labeled manual true-200-percent browser-zoom observation; long-title observations.
