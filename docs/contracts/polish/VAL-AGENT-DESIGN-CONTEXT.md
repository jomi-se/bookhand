# VAL-AGENT-DESIGN-CONTEXT: Runtime design guidance for browser agents

Surface: genuine WebMCP browser runtime, tool metadata, and visible Agent Activity.
Needs: secure production preview, `WebMCPTesting`, canonical `DESIGN.md`, and the versioned runtime design-context artifact.
Behavior: `get_design_context` is a read-only tool available at the library and after book open. For `library`, `reader`, and `study`, its response is at most 6,000 UTF-16 code units and returns the current guidance version; active/requested surface; viewport class; safe named/custom-theme summary; bounded style summary; board view; available mutation tools; supported semantic roles and primitives; mutation containment; four to six task-relevant composition/accessibility/user-control invariants; and available reversal actions. Unavailable live fields are explicit rather than invented. The version is `sha256:<64-lowercase-hex>` over the exact UTF-8 bytes between `bookhand:agent-design-context:start` and `bookhand:agent-design-context:end` markers in canonical `DESIGN.md`, not a separately chosen constant. The response contains no book text, raw custom CSS, notes, study payloads, or other user-authored values and requires no repository or harness-skill access. It says creative palette, typography, shape, and composition changes are unrestricted within supported scopes, distinguishes current EPUB-CSS and native-Study scopes, and truthfully identifies whole-application custom worlds as unavailable until their ADR, declarative schema, and lifecycle contract are implemented. Descriptions for custom CSS, `upsert_study_item`, and cohesive study-experience mutations direct agents to this tool; routine one-block calls do not require a version handshake. Design-context reads are visible in Agent Activity but create no persistent user data.
Evidence: exact `getTools()` names, descriptions, and serialized schemas before and after book open; genuine tool calls for all three surfaces with output-length, version, every required live field, unavailable-state, scope/freedom, and no-book/raw-CSS/user-content assertions; independent extraction and SHA-256 recomputation from the marked `DESIGN.md` block; changed-block mismatch regression; Agent Activity screenshot plus unchanged user storage; no unexpected console/network error or book-content egress.

Fail: A repository skill, copied user prompt, direct handler call, full design-document dump, leaked user-authored value, or false claim that whole-application customization is already supported cannot satisfy runtime discovery.
