# VAL-STUDY-WORKSPACE-RESPONSIVE: Docked companion and focused workspace

Surface: reader/study layout and browser.
Needs: `VAL-BOARD-VIEW-PARITY` and `VAL-STUDY-COMPOSITION-HIERARCHY`.
Behavior: Docked desktop is a concise companion that preserves a useful book measure; expanded desktop is a meaningfully different centered lesson workspace with optional lesson navigation/source or annotation rail, not merely the same feed widened. On mobile, focused Study cleanly replaces the reader and exposes an obvious return; docked preference does not create a squeezed split. Every mode preserves reading location, supports long content and 200-percent reflow, and uses semantic theme roles across light, sepia, dark, publisher, and safe custom themes.
Evidence: Measured geometry and screenshots for docked/expanded desktop, mobile replacement, 320-pixel width, 200-percent reflow, long lesson, every shipped theme, focus entry/return, and unchanged reader location.
