# VAL-SOURCE-EXCERPT-LIFECYCLE: Canonical source meaning survives time

Surface: reader adapter, domain, storage worker, search, and browser.
Needs: `VAL-MATH-PASSAGE`, `VAL-RANGE-OWNERSHIP`, and schema migration support.
Behavior: Source-linked records use a versioned typed excerpt containing book identity, exact range, extraction version, canonical accessible text of at most 32,000 UTF-16 code units, fingerprint, and at most 64 ordered text/math/figure segments of at most 8,000 code units each. A newly supplied source-derived quotation is canonicalized from that excerpt; a user-authored quotation is preserved as authored content and linked to, not overwritten by, refreshed source. During migration, a pre-version excerpt whose exact CFI and book still verify upgrades derived source fields automatically without changing authored text. An unverifiable record keeps its original display text, shows a stale-source state, and offers Retry resolution or Relink—not a Refresh action that cannot succeed. Reindexing follows extraction-version change. Identical annotation references and quotations are related or proposed for deduplication without silently deleting user content; raw XHTML is never persisted as the repair mechanism.
Evidence: Schema migration and rollback-safe fixtures; Chapter XIX automatic derived-data repair and unresolvable Retry/Relink stale state; authored-text preservation; invented source-derived quotation rejection/canonicalization; annotation-reference deduplication proposal/acceptance; persistence/reload/reindex traces; no raw renderable EPUB markup in stored excerpts.
