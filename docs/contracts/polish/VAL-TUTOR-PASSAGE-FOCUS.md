# VAL-TUTOR-PASSAGE-FOCUS: An agent can point at an exact passage

Surface: command API, reader adapter, genuine WebMCP, and browser.
Needs: `VAL-TUTOR-SESSION-LIFECYCLE`, `VAL-RANGE-OWNERSHIP`, and `VAL-SEARCH-BOOK`.
Behavior: `focus_passage` accepts `{ bookId, range, quote, indicatorMessage?, cue? }`, where `range` is the exact range object returned by another Bookhand tool; the previously shipped flattened `{ bookId, sectionIndex, startCfi, endCfi, cfi?, textFingerprint, quote, indicatorMessage?, cue? }` shape remains accepted for compatibility, and mixing the two shapes rejects. `indicatorMessage` is plain text of at most 1,000 UTF-16 code units. It verifies the complete source, atomically records or preserves the session origin under `VAL-TUTOR-SESSION-LIFECYCLE`, navigates, reveals the exact target in the reader viewport, installs the attributed guidance indicator, and delegates transient emphasis to `VAL-TUTOR-PASSAGE-CUE`. Its exact outcomes are `applied|superseded|rejected|unavailable`, each returning the resulting `guidance` block. Wrong-book, stale, malformed, partial, invented, or unresolvable sources return `rejected` with bounded detail or candidates and change nothing. Guidance during reader restore returns `unavailable`; a failed or superseded move cannot install or resurrect a session. Guidance never changes the location value stored in `ReadingState`: style writes and lifecycle flushes may write the record, but carry the session-origin location while guidance owns the anchor. Back, Stop, takeover, close, detach, unmount, and reload follow `VAL-TUTOR-SESSION-LIFECYCLE`.
Evidence: Serialized exact schema and result union; genuine search-to-focus tool trace with `sectionIndex`, exact CFIs, quote/fingerprint, visible target, and guidance state; wrong-book/stale/malformed/partial/invented/unresolvable rejection; reader-opening race; superseded interleaving at every await boundary; exact stored location/style values and write ordering; Back/Stop/takeover/close/detach/unmount; style persistence during guidance; reload returning to the learner-owned origin with guidance absent.
