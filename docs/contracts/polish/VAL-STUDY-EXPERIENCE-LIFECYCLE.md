# VAL-STUDY-EXPERIENCE-LIFECYCLE: Atomic persistent lesson lifecycle

Surface: command API, genuine WebMCP, storage worker, and browser.
Needs: `VAL-AGENT-DESIGN-CONTEXT`, `VAL-STUDY-SCHEMA-SECURITY`, `VAL-INTERACTIVE-PLOT`, `VAL-STUDY-ID-OWNERSHIP`, and `VAL-TUTOR-SESSION-LIFECYCLE`.
Discovery: After reload, `list_study_items` returns at most 100 standalone-item and first-class experience summaries containing current-book ID, title, kind, source label, and revision; it does not return full lesson payloads unless requested by ID. This makes durable lessons discoverable inputs to `reveal_study_item`.
Discovery evidence: Genuine post-reload `list_study_items` calls prove experience summaries remain discoverable and usable by `reveal_study_item`.
Behavior: One atomic command creates or idempotently updates one titled, ordered, source-linked experience using the current `designContextVersion`; a missing or stale version changes nothing and directs the caller to refresh. The experience owns shared sources, optional block-specific sources, annotation references, provenance, revision, and one action boundary; `actionGroupId` alone is not lesson identity. Follow-up uses the same ID; validated content renders with active semantic theme roles and reload preserves it. The mutation receipt returns structured prior and applied state, visible scope, warnings, provenance, persistence, and exact user-visible Undo, Reset, Return to source, and removal affordance. Undo of creation removes it; Undo of update restores its prior version while preserving interleaved later user edits. Source navigation uses the shared guidance/navigation controller and visible Back. Reset changes only interactive state; removal safety is owned by `VAL-STUDY-SAFE-REMOVAL`; rejected or mid-write calls leave zero partial records and show a bounded error; unrelated/user content survives every operation.
Evidence: Genuine design-context then tool create/update trace and exact schemas/structured receipt fields; missing/current/stale version calls with before/after UI and storage state; title/order/shared-and-differing-source/annotation-reference rendering; semantic-token rendering under shipped themes; provenance round trip; mid-write fault with zero partial records and visible error; same-ID/idempotency assertions; reload; creation/update Undo with interleaved user edit; source-return plus Back round trip; Reset and removal-affordance presence; unrelated-content snapshots. Removal execution is evidenced only by `VAL-STUDY-SAFE-REMOVAL`.
