# VAL-STUDY-EXPERIENCE-LIFECYCLE: Atomic persistent lesson lifecycle

Surface: command API, genuine WebMCP, storage worker, and browser.
Needs: `VAL-AGENT-DESIGN-CONTEXT`, `VAL-STUDY-SCHEMA-SECURITY`, `VAL-INTERACTIVE-PLOT`, and `VAL-STUDY-ID-OWNERSHIP`.
Behavior: One atomic command creates or idempotently updates one source-linked experience using the current `designContextVersion`; a missing or stale version changes nothing and directs the caller to refresh. Follow-up uses the same ID; prose, citation, equation, plot configuration, and question come from the validated caller payload; native rendering consumes the active semantic theme roles and reload preserves it. The mutation receipt returns prior and applied state, visible scope, sanitizer/validation warnings, provenance and action-group ID, persistence result, and the exact user-visible Undo, Reset, Return to source, and Delete actions. Undo of creation removes it; Undo of update restores its prior version while preserving interleaved later user edits. Return to source first saves the current reading location as a visible Back target, navigates to the exact citation, and Back restores the pre-jump location. Reset changes only interactive state, Delete removes only that experience, rejected or mid-write calls leave zero partial records and show a bounded error, and unrelated/user content survives every operation.
Evidence: Genuine design-context then tool create/update trace and exact schemas/receipt fields; missing/current/stale version calls with before/after UI and storage state; semantic-token rendering under shipped themes; provenance/action-group round trip; mid-write fault with zero partial records and visible error; same-ID/idempotency assertions; reload; creation/update Undo with interleaved user edit; source-return plus visible Back round trip; Reset/Delete traces; unrelated-content snapshots.
