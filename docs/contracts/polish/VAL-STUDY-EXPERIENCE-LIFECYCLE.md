# VAL-STUDY-EXPERIENCE-LIFECYCLE: Atomic persistent lesson lifecycle

Surface: command API, genuine WebMCP, storage worker, and browser.
Needs: `VAL-STUDY-SCHEMA-SECURITY`, `VAL-INTERACTIVE-PLOT`, `VAL-STUDY-ID-OWNERSHIP`, and reactivated `VAL-TEST-CONTROL-INTEGRITY` covering the `experienceFailBeforeCommit` seam.
Behavior: One atomic command creates or idempotently updates one source-linked experience; follow-up uses the same ID; prose, citation, equation, plot configuration, and question come from the validated caller payload; reload preserves it. The experience records agent/user provenance and an action-group ID. Undo of creation removes it; Undo of update restores its prior version while preserving interleaved later user edits. Return to source first saves the current reading location as a visible Back target, navigates to the exact citation, and Back restores the pre-jump location. Reset changes only interactive state, Delete removes only that experience, rejected or mid-write calls leave zero partial records and show a bounded error, and unrelated/user content survives every operation.
Evidence: Genuine tool create/update trace and exact schemas; provenance/action-group round trip; mid-write fault with zero partial records and visible error; same-ID/idempotency assertions; reload; creation/update Undo with interleaved user edit; source-return plus visible Back round trip; Reset/Delete traces; unrelated-content snapshots.
