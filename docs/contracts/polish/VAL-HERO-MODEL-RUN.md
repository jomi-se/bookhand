# VAL-HERO-MODEL-RUN: A real model composes the deployed hero lesson

Surface: deployed secure origin in a compatible agent browser.
Needs: `VAL-AGENT-DESIGN-CONTEXT`, `VAL-SEARCH-BOOK`, `VAL-TUTOR-PASSAGE-FOCUS`, `VAL-TUTOR-PASSAGE-CUE`, `VAL-TUTOR-PRESENTATION-SAFETY`, `VAL-TUTOR-STUDY-REVEAL`, `VAL-STUDY-EXPERIENCE-LIFECYCLE`, `VAL-DEPLOYED-RUNTIME-TRUTH`, and the deployed commit hash.
Behavior: A named model/version receives an intent-only request to help with the open Chapter X passage; the prompt contains no design-system prose, lesson prose, citations, answers, plot configuration, coordinates, or tool payload. The model discovers and originates real `document.modelContext` calls: it reads context, searches, visibly focuses an exact passage, and presents a bounded temporary explanation. The learner then activates visible Back or Stop through the UI before asking for durable content; this human action cannot be replaced by a model-originated `control_guidance` call. Only when asked, the model reads design context, creates one titled lesson, reveals it, and updates the same experience after an intent-only follow-up. Reload preserves the lesson and clears tutor state; a deliberately invalid follow-up produces visible bounded failure. Replayed output, deterministic relay/orchestration, direct handler/command calls, or hard-coded final content cannot satisfy this contract.
Evidence: Fresh independently witnessed transcript and runtime trace naming model, version, compatible agent browser, runtime, deployed commit/assets, and secure origin; exact prompts; ordered model-originated context/search/focus/presentation/design/mutation/reveal calls with bounded structured results; separately recorded learner UI activation of visible Back or Stop; transient-clears-on-reload evidence; model-supplied durable payload; visible creation/follow-up/error/reload recording; repository inspection showing final lesson copy/configuration is absent.
