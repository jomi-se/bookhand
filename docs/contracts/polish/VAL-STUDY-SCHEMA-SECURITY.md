# VAL-STUDY-SCHEMA-SECURITY: Generic bounded native experience schema

Surface: domain parser, renderer, and production browser.
Needs: `VAL-RANGE-OWNERSHIP`, `VAL-MUTATION-ERRORS`, and production CSP.
Behavior: The v0 block discriminators are exactly `markdown` (plain CommonMark subset: paragraphs, emphasis, strong, lists, code; raw HTML and links disabled), `quotation` (plain quote plus validated internal citation), `equation` (TeX string rendered as text/math, never HTML), `steps` (1–12 titled/plain steps), `callout` (`note|tip|warning` plus title/body), `question` (prompt plus revealable answer), `mermaid` (flowchart-only source rendered by a locked-down parser with clicks/HTML/securityLevel-loose disabled), and `interactive_plot` (the declarative plot below). A generic experience has 1–16 ordered blocks, nesting depth at most 6, at most 64 entries per array and 32 own keys per object, at most 8,000 UTF-16 code units per string and 64,000 across the payload. It allows at most 4 plots, 8 series per plot, and 512 explicit points per series. It rejects prototype-shaped, unknown, and other discriminator fields. Caller URLs are disallowed in v0: citations use validated internal book/range IDs and the renderer creates targets. All strings are untrusted and cannot supply HTML/script/event/CSS/resource behavior. Curves use bounded data or a validated math AST with at most 64 nodes and depth 8; nodes are finite literals, `x`, declared finite parameters, unary negation, or binary add/subtract/multiply/divide/integer-power. Literals and parameters have absolute value at most 1,000,000; integer exponents are -12 through 12; plot domains are finite within -10,000 through 10,000 with span at least 0.000001. Division by zero or non-finite evaluation yields a bounded plot gap, not executable fallback. `eval`, `Function`, dynamic module/script creation, caller expressions, and equivalent compilation paths are forbidden.
Evidence: Frozen fixtures `tests/fixtures/study-experience/slope.json`, `non-slope.json`, and `hostile.json` define exact accepted/rejected payloads and rendered/numerical oracles. Tests cover every block, AST node, limit, and forbidden executable form; malicious browser evidence proves no script, parent/storage access, or non-origin request; visible errors and CSP trace are preserved. Production domain/rendering/source scans must show no oracle title/copy, Chapter X copy, fixed `x²` lesson, fixture coordinates, expected numerical outputs, or hostile sentinel branches.
