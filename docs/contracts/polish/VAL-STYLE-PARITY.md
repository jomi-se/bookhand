# VAL-STYLE-PARITY: Observable and reversible reading style

Surface: UI and genuine WebMCP browser runtime.
Needs: `VAL-READER-STYLE`, `VAL-AGENT-DESIGN-CONTEXT`, secure production preview, and `WebMCPTesting`.
Behavior: UI Preview remains temporary, Cancel restores prior computed presentation, Apply persists, Reset restores the publisher baseline, and a tool style change immediately updates controls and computed EPUB/shell styles, survives reload, preserves the source anchor, and cannot be overwritten by a later unrelated control change. Its receipt returns prior and applied state, visible scope, sanitizer/validation warnings, provenance and action-group ID, persistence result, and the exact user-visible Undo and Reset actions. Custom EPUB CSS carries the current design-context version and is truthfully identified as EPUB-scoped; a missing or stale version changes nothing and returns a recoverable refresh instruction. Named themes and ordinary typography remain callable without that handshake. Undo restores the returned prior style after reload-safe persistence.
Evidence: Paired UI/tool traces; exact receipt fields; control and computed-style assertions; anchor/quote before and after reflow; Preview/Cancel/Apply/Reset/reload; missing/current/stale design-version custom-CSS calls with before/after UI and storage state; visible scope and sanitizer warnings; tool change then Undo; tool-then-unrelated-control race; invalid custom CSS rejection.
